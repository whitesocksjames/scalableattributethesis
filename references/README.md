# Thesis References

This directory stores read-only methodological and project-scope references for the scalable attribute thesis.

## Reference precedence

1. The official Unicorn-v1 source code is the implementation ground truth.
2. The Unicorn Part II: Attribute paper explains architecture motivation, terminology, and training methodology.
3. If the paper and released source differ, implementation follows the released source.

Geometry is out of scope and must not be modified.

## Files

- `thesis_task_description.pdf`: official Master Thesis task description.
- `unicorn_part_ii_attribute.pdf`: reserved filename for the Unicorn Part II: Attribute paper once its PDF is available in this workspace.
