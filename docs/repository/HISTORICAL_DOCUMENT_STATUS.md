## Claim boundary

The thesis contribution is a **full-resolution quality-scalable extension of
Unicorn Part II**, with flow `native truncated Unicorn prefix → learned
BaseSynthesis → full-resolution Base → conditional Enhancement → Full`.
Unicorn already contains progressive residual refinement. Base+Enhancement
layering is not claimed as a first, and the final evidence supports
"competitive but not uniformly superior," not blanket outperformance.
